01. Fundamentos Teóricos

Definiciones y Ecuaciones

Las secciones cónicas son curvas que resultan de intersecar un cono circular recto con un plano en distintos ángulos.

Circunferencia

Lugar geométrico de todos los puntos del plano que mantienen una distancia constante (radio $r$) respecto a un punto fijo llamado centro $C(h, k)$.

Ecuación Ordinaria
(x - h)² + (y - k)² = r²
Canónica C(0,0)
x² + y² = r²

Parábola

Lugar geométrico de los puntos que equidistan de un punto fijo llamado foco $F$ y de una recta fija llamada directriz. El parámetro $p$ define su apertura.

Vertical / Horizontal
(x - h)² = 4p(y - k)
(y - k)² = 4p(x - h)

Elipse

Lugar geométrico de los puntos cuya suma de distancias a dos puntos fijos (focos $F_1, F_2$) es constante e igual a $2a$. Siempre se cumple $a > b$.

Horizontal / Vertical
(x-h)²/a² + (y-k)²/b² = 1
(x-h)²/b² + (y-k)²/a² = 1

Cuadro Resumen de Ecuaciones y Orientación

Comparación con la Ecuación General: Ax² + Cy² + Dx + Ey + F = 0

Cónica y Orientación Canónica C(0,0) Ordinaria C(h,k) Orientación y Variables Condición General
Circunferencia x² + y² = r² (x - h)² + (y - k)² = r² Simétrica en todas direcciones. r = radio (r > 0). A = C (mismo valor y signo)
Parábola Vertical
(Abraza al eje Y)		 x² = 4py (x - h)² = 4p(y - k) Si p > 0 abre arriba ↑
Si p < 0 abre abajo ↓		 C = 0 (solo x² al cuadrado)
Parábola Horizontal
(Abraza al eje X)		 y² = 4px (y - k)² = 4p(x - h) Si p > 0 abre derecha →
Si p < 0 abre izquierda ←		 A = 0 (solo y² al cuadrado)
Elipse Horizontal
(Aplastada)		 x²/a² + y²/b² = 1 (x-h)²/a² + (y-k)²/b² = 1 El mayor (a²) está debajo de x. Se alarga en X. A ≠ C (suman, distinto valor)
Elipse Vertical
(Alargada)		 x²/b² + y²/a² = 1 (x-h)²/b² + (y-k)²/a² = 1 El mayor (a²) está debajo de y. Se alarga en Y. A ≠ C (suman, distinto valor)

03. Aplicación en el Entorno

Evidencias Fotográficas Reales

Observación directa de las tres secciones cónicas en objetos cotidianos capturados esta semana.

Circunferencia

Borde Superior de Maceta

Vista cenital de una maceta cilíndrica. Todo el contorno del borde mantiene exactamente la misma distancia (radio r) desde el centro geométrico del recipiente.

x² + y² = r²
Parábola Vertical

Cuello Curvo de Grifo

El arco superior del grifo describe una parábola vertical que abre hacia abajo (p < 0), alcanzando su punto máximo en el vértice superior antes de descender.

(x - h)² = 4p(y - k)
Elipse

Contorno de Lavamanos

La estructura ovalada del lavamanos forma una elipse con dos ejes de simetría perpendiculares: un eje mayor (2a) y un eje menor (2b).

x²/a² + y²/b² = 1
